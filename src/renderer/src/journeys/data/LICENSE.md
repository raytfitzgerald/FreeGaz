# Journey data

The `*.json` files here are generated by `scripts/journeys/build.mjs` from:

- **Roads:** © OpenStreetMap contributors, available under the [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Routed for bikes with [BRouter](https://brouter.de) (trekking profile). These files are a derived database and are made available under the ODbL, unlike the rest of the repository (MIT).
- **Elevation:** NASA Shuttle Radar Topography Mission (SRTM GL1, 30 m), public domain, via [OpenTopoData](https://www.opentopodata.org).
- **Borders:** found with [Nominatim](https://nominatim.org) reverse geocoding on OpenStreetMap data (ODbL).

The app credits OpenStreetMap on every journey map and in Settings → Journeys.
